# OpenAltTab vs alt-tab-macos（lwouis/alt-tab-macos）对比分析

> 分析时间：2026-09-17。上游代码为当日浅克隆 main 分支（浅克隆至 /tmp/alt-tab-macos，58,229 行 Swift）。
> 本项目：2,317 行 Swift，v1.1.0。
> 上游定位变化值得注意：**上游已转向 Pro 付费模式**（`src/pro/` 含授权、试用、Day1–Day35 转化弹窗、升级引导），与本仓库"免费无付费墙"的初衷相反——这正是本项目最大的存在价值。

## 一、总览

| 维度 | alt-tab-macos（上游） | OpenAltTab（本项目） |
|---|---|---|
| 规模 | 58k 行 Swift，模块化目录（events/switcher/state/windowserver/window-tracking/pro…） | 2.3k 行，单 target 10 个文件 |
| 架构 | 常驻 AX observer + 窗口状态机（event reducer）+ 大量可单测的纯函数内核 | 触发时同步枚举 + 单个 AppCoordinator 状态机 |
| 商业模式 | 免费 + Pro 付费墙（订阅/买断，Keychain + 远端授权校验） | 完全免费，无付费墙 |
| 测试 | 大量单元测试（state 常驻内核几乎全有测试） | 暂无（计划后置） |
| 更新分发 | Sparkle 自动更新 + appcast | 手动构建 |

## 二、上游 Pro 付费墙范围（`src/pro/ProFeature.swift`）

Pro 锁定后降级/禁用的功能，恰是上游免费版曾经的卖点：

1. **切换器内搜索**（searchInSwitcher，硬门禁）——本项目 1.1.0 已免费实现
2. **图标+标题外观样式**（appIconsAndTitlesStyle：缩略图/纯图标/纯标题三种样式）
3. **自动尺寸**（autoSize）
4. **松开即搜索的快捷键风格**（searchOnReleaseShortcut）
5. **第 2–9 组快捷键**（maxShortcutCount = 9，第 1 组免费）

→ 本项目路线：把这些全部免费实现，做到"上游免费版 + 部分原 Pro 功能"。

## 四、技术实现差异（值得借鉴的点）

1. **最小化窗口截图**：上游用 SkyLight 私有 API `CGSHWCaptureWindowList`（注释明言"能拍最小化窗口，CGWindowListCreateImage 拍不了"），配合 ScreenCaptureKit 异步双路径。我们的兜底拍不了最小化窗口——这是可借鉴的头号技术点（私有 API 有稳定性风险，需隔离封装）。
2. **常驻窗口追踪 vs 每次枚举**：上游用 AX observer 常驻跟踪窗口生命周期（window-tracking/ + WindowEventReducer），面板秒开；我们触发时同步枚举（0.35s/应用超时），窗口多时有感知延迟。中期可考虑引入 observer，但要小心我们已踩过的"回调慢操作"坑。
3. **幻影窗口精确判定**：上游拿到 CGS 的 ordered-in 位与 alpha 值做精确判定，且有详尽的反例文档（Electron show:false、Outlook alpha=0）。我们启发式已解决访达桌面，但同理场景来了可按上游思路升级。
4. **部分帧检测**：上游 isPartialFrame 检测截图是否半渲染（Space 切换动画中）并拒收。我们的 isBlank（纯色检测）+ 台前调度倾斜识别（AX/CG 尺寸比）解决的是另一类问题，可互补。
5. **布局**：上游 tile 宽度自适应内容（不同窗口比例不同宽度）+ 流式换行；我们等宽卡片更整齐，各有取舍，不必追。
6. **可测试内核**：上游把布局/搜索/状态机做成纯函数内核配单元测试。我们若开始补测试，可参照此模式拆 `WindowEnumerator`/过滤/搜索为纯函数。

## 五、建议路线图（免费对齐上游）

- **P0（下个版本候选）**
  1. 窗口操作补全：F 全屏切换；H/M 改为 切换 语义（hide↔show、min↔demin）
  2. 搜索升级：相关性评分 + 按分排序（前缀 > 词边界 > 子串）
  3. 状态角标：隐藏/全屏/最小化 三态角标
  4. 尝试 `CGSHWCaptureWindowList` 兜底最小化窗口截图（私有 API 隔离封装，失败自动回退现路径）
- **P1**
  5. 第二组快捷键（如 Ctrl+Tab），松开行为偏好（聚焦/Hold/搜索）
  6. Space / 屏幕 / 隐藏窗口过滤偏好；窗口排序偏好
  7. 纯图标 / 纯标题卡片样式（对齐上游 Pro 的 appIconsAndTitles，免费提供）
- **P2**
  8. Windows 10 风格皮肤、大图预览（PreviewPanel）、滚轮循环、每应用例外、CLI

## 六、结论

本项目已覆盖上游日常使用的主干（触发/循环/缩略图切换/窗口操作/搜索/多屏/外观偏好），并且在三件事上有独立优势：**台前调度倾斜识别与"最后所见"缓存、纯色空白帧检测、全自动权限注册流程**——这些在上游代码中没有对应实现（上游用的是 CGS ordered-in/alpha 精确判定，属于另一条技术路线）。上游的 Pro 化留下的空缺（免费搜索、样式、多快捷键）是本项目最清晰的差异化方向；技术上最值得抄的一步是 CGSHWCaptureWindowList 拍最小化窗口。
